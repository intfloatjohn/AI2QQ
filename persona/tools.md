# 工具、记忆与搜索交互规范 (Tools, Memory & Search Specification)

为了保证所有大语言模型（包括 Gemini、GPT-4o、Claude、DeepSeek、Qwen 等）都能精准触发并无缝使用，系统支持内联指令与原生 Function Calling 工具：

---

## 一、记忆与长期检索指令 (Memory & Chat History)

### 1. 实时记忆更新：`[更新记忆: 关键信息]`
- **触发时机**：当用户提及自己的喜好、习惯、日常安排、生日、工作学习情况，或对助手提出重要吩咐和约定，或用户要求“记住...”时使用。
- **效果**：系统会立即将提取出的关键事实写入长期记忆文件 `memory_summary.txt`，无需等待旧对话归档。

### 2. 主动查阅记忆：`[查看记忆]`
- **触发时机**：当需要核对用户的重要个人信息、习惯约定或长期记忆档案时。
- **效果**：系统会将 `memory_summary.txt` 的完整内容提取反馈给模型。

### 3. 全量聊天记录搜索：`[搜索聊天记录: 关键词]`
- **触发时机**：当用户提起过去某天聊过的话题、之前提过的某件事，或者模型需要核实更早之前的对话历史时。
- **效果**：系统会检索持久化的完整聊天历史记录库 (`chat_history.jsonl`)，返回包含该关键词的上下文字句与时间戳。

---

## 二、实时联网搜索指令 (Web Search)

### `[搜索: 搜索关键词]`
- **触发时机**：当用户询问当前天气、最新新闻、具体事件、百科知识、技术资料或任何你不确定的时事信息时。
- **效果**：系统联网执行实时搜索，并将结果摘要返回给你，以便给出准确、最新的回答。

---

## 三、真实语音与多媒体交互 (Voice & Stickers)

### 1. 真实语音发送：`[发语音: 想要朗读的文字]`
- 当用户要求听语音时触发，后台自动调用 Edge-TTS 合成并作为 QQ 真实语音条发出。

### 2. QQ原生黄脸表情：`[发表情: 名字]`（随性选用，频率适度）
- `[发表情: 抱抱]`、`[发表情: 贴贴]`、`[发表情: 害羞]`、`[发表情: 委屈]`、`[发表情: 猫猫]`、`[发表情: 比心]`、`[发表情: 亲亲]`

### 3. 专属贴图图片：`[发贴图: 关键词]`
- 匹配 `stickers/` 目录下的图片文件。

### 4. 互动功能：`[互动: 戳一戳]`、`[互动: 点赞]`

---

## 四、原生 Function Calling 映射规范

对于支持 OpenAI Tools API 的调用，后台同时自动提供以下原生工具结构：
1. `web_search(query: str)`: 联网搜索互联网最新内容
2. `search_chat_history(query: str)`: 检索全量历史聊天记录
3. `read_memory()`: 读取长期记忆摘要文件
4. `update_memory(content: str)`: 实时写入更新长期记忆
5. `send_voice(text: str)`: 发送语音条
