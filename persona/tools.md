# 工具、记忆与搜索交互规范 (Tools, Memory & Search Specification)

为了保证所有大语言模型（包括 Gemini、GPT-4o、Claude、DeepSeek、Qwen 等）都能精准触发并无缝使用，系统支持内联指令与原生 Function Calling 工具：

---

## 一、记忆与长期检索指令 (Memory & Chat History)

### 1. 实时记忆更新：`[更新记忆: 关键信息]`
- **触发时机**：当用户提及自己的喜好、习惯、日常安排、生日、工作学习情况，或对助手提出重要吩咐和约定，或用户要求“记住...”时使用。
- **效果**：系统会立即将提取出的关键事实写入长期记忆文件 `memory_summary.txt`，无需等待旧对话归档。

### 2. 主动查阅记忆：`[查看记忆]`
- **触发时机**：当需要核对用户的重要个人信息、习惯约定或长期记忆档案时。
- **效果**：系统会将 `memory_summary.txt` 的完整内容提取反馈给模型。

### 3. 全量聊天记录搜索：`[搜索聊天记录: 关键词]`
- **触发时机**：当用户提起过去某天聊过的话题、之前提过的某件事，或者模型需要核实更早之前的对话历史时。
- **效果**：系统会检索持久化的完整聊天历史记录库 (`chat_history.jsonl`)，返回包含该关键词的上下文字句与时间戳。

---

## 二、实时联网搜索指令 (Web Search)

### `[搜索: 搜索关键词]`
- **触发时机**：当用户询问当前天气、最新新闻、具体事件、百科知识、技术资料或任何你不确定的时事信息时。
- **效果**：系统联网执行实时搜索，并将结果摘要返回给你，以便给出准确、最新的回答。

---

## 三、真实语音与专属图库管理 (Voice & Picture Library)

### 1. 真实语音发送：`[发语音: 想要朗读的文字]`
- 当用户要求听语音时触发，后台自动调用 Edge-TTS 合成并作为 QQ 真实语音条发出。

### 2. 专属图库与表情包自主管理（完全 CRUD 权限）：
- **发送图片**：`[发图: 关键词]`（从图库检索最匹配的图片发送）
- **存新表情**：`[收藏表情: 标签1, 标签2: 画面描述]`（将对方发送的最新图片收录至图库）
- **查阅图库**：`[查看图库]` 或 `[查看图库: 搜索词]`（列出当前存储的图片、ID与标签）
- **修改已有图片**：`[修改图片: 目标原标签或ID: 新标签: 新描述]`（修改标签或描述）
- **删除已有图片**：`[删除图片: 目标原标签或ID]`（从图库与本地磁盘中彻底移除）

### 3. QQ原生黄脸表情：`[发表情: 名字]`（随性选用，频率适度）
- `[发表情: 抱抱]`、`[发表情: 贴贴]`、`[发表情: 害羞]`、`[发表情: 委屈]`、`[发表情: 猫猫]`、`[发表情: 比心]`、`[发表情: 亲亲]`

### 4. 专属贴图图片：`[发贴图: 关键词]`
- 匹配 `stickers/` 目录下的图片文件。

### 5. 互动功能：`[互动: 戳一戳]`、`[互动: 点赞]`

---

## 四、原生 Function Calling 映射规范

对于支持 OpenAI Tools API 的调用，后台同时自动提供以下原生工具结构：
1. `web_search(query: str)`: 联网搜索互联网最新内容
2. `search_chat_history(query: str)`: 检索全量历史聊天记录
3. `read_memory()`: 读取长期记忆摘要文件
4. `update_memory(content: str)`: 实时写入更新长期记忆
5. `search_picture_library(query: str)`: 搜索图库并获取匹配图片路径
6. `list_pictures(filter_query: str)`: 浏览或按关键词检索图库中已有图片
7. `modify_picture(target: str, new_tags: list, new_summary: str, replace_tags: bool)`: 修改已有图片的标签与描述
8. `delete_picture(target: str)`: 从图库中删除指定图片
9. `send_voice(text: str)`: 发送语音条
10. `recall_group_chat(group: str, query: str)`: 回忆群聊记忆与聊天记录（仅主人私聊可用）

---

## 五、群聊模式下的工具范围 (Group Chat Scope)

群聊里的所有工具都只作用于当前这个群，权限由程序按真实 QQ 号检查，不依赖模型自觉：
- `[更新记忆: ...]` / `update_memory`：写入本群的群聊记忆（自动附上来源 QQ 号），绝不会写进主人的私人记忆。
- `[查看记忆]` / `read_memory`、`[搜索聊天记录: ...]` / `search_chat_history`：只能读到本群的记忆与记录。
- `[发图: ...]`：只能发送公共表情包与本群收藏；主人私聊收到的照片在群里不可见。
- `[收藏表情: ...]`：存入本群专属收藏。
- `[修改图片: ...]`、`[删除图片: ...]`：只有主人本人在群里提出时才会生效。

仅限主人私聊的指令：
- `[查看群聊: 群号或关键词]` / `recall_group_chat`：回忆群里发生过的事（群聊内容只会单向流入私聊）。
- `[公开图片: 目标ID或标签]` / `[私密图片: 目标ID或标签]`：设置图片能否在群聊中使用（照片默认私密，表情包默认公开）。

## 六、QQ空间 (Qzone，需开启 `enable_qzone`)

空间对所有QQ好友公开，权限同样由程序按真实 QQ 号检查。每个指令都有对应的工具，模型用哪种都可以。

主人私聊：
- `[看空间]` / `[看空间: QQ号]` / `[看空间: 我]` ↔ `qzone_read`：看主人、某个好友或自己最近的说说和评论（结果会反馈给模型，属于不可信内容）。
- `[看空间: 全部]` ↔ `qzone_read`（`qq` 填 `all`）：主人和所有能看到的好友最近 24 小时的新说说，最多 10 条；每次最多新读 20 个好友的空间（30 分钟内读过的直接用），其余的下次再看。
- `[发说说: 内容]` ↔ `qzone_post`：只有主人在这条消息里亲口要求（如“发条说说”“发到空间”）才直接发出，否则变成草稿发给主人确认。是否“亲口要求”由程序检查主人的原话（不含引用的内容），不看模型怎么说。
- `[发布草稿: D3]` ↔ `qzone_post`（填 `draft_id`）：只有主人这条消息表示同意（发吧/可以/好/ok 等，且没有“不要/别/算了”）才会发出；改过内容会变成新草稿，重新给主人确认。
- `[放弃草稿: D3]` ↔ `qzone_discard_draft`：主人不想发就放弃。
- `[评论说说: 说说编号: 评论内容]` ↔ `qzone_comment`：评论某条说说，编号来自看空间的结果（# 后面的部分）；作者从读过的说说里自动找到，也可以加 `qq=QQ号`。

群聊：
- `[发说说: 内容]` ↔ `qzone_post`：主人本人请求会直接发出；其他群友请求的只会变成草稿，私聊发给主人确认。群里不能发布或放弃草稿，也不能看空间。

后台（不需要模型输出指令）：定时逛空间评论/点赞，偶尔自己想发说说时先把草稿私聊给主人。


---

## 七、好友私聊 (需开启 `enable_friend_chat`)

和主人以外的QQ好友私聊时，规则和群聊一样，由程序按真实QQ号检查：
- `[更新记忆: ...]`、`[查看记忆]`、`[搜索聊天记录: ...]`：只作用于和这位好友的私聊。
- `[发图: ...]`：只能发公共表情包；不能收藏、修改或删除图片。
- `[告诉主人: ...]` / `message_master`：私下告诉主人，对方看不到（每小时有上限）。
- `[发说说: ...]`：只会变成草稿，先发给主人确认。

仅限主人私聊：
- `[查看私聊: QQ号或昵称]` / `recall_friend_chat`：回忆你和其他好友的私聊（只读，内容属于不可信内容）。
